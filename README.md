# 📊 Adventure Works Sales & Profitability Dashboard

## 📌 Project Overview

This project analyzes multi-table transactional sales data from Adventure Works to evaluate revenue, cost of goods sold (COGS), profit margins, product performance, and customer demographics across regions.

The dashboard was developed using advanced Excel features including Power Query, Power Pivot, Data Modeling, and DAX.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- Data Modeling
- Excel Dashboarding

## 🔄 Project Workflow

Raw Data
→ Power Query
→ Data Cleaning & Transformation
→ Data Modeling
→ DAX Measures
→ Interactive Excel Dashboard
